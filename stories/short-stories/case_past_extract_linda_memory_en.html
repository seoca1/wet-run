Linda Had Been a Memory

Linda had been a memory for forty years. The memory had been Linda. The memory had been the construct. The construct had been the memory. The memory had been the construct. The construct had been the apartment.

I had been hired to extract the memory. The job description was four lines in a Fukuoka-script terminal in the third-tier ward. The job description said: The memory is in the apartment. The memory is not in her. The memory is in the apartment. Extract the memory. Do not extract her.

I had not known, when I took the job, that the memory was not in her. I had assumed the job was the kind of job I had stopped taking — the kind of job that involved a Fukuoka subroutine in a cortex room and a memory extracted by force. I had been a cowboy. Cowboys extract memories by force. Cowboys do not extract memories from apartments.

I had been, I realized when I got to the Mesa district, no longer a cowboy. I had been, since Minneapolis, since the part of me that sang had been scooped out and replaced with a part of me that did not sing, a person who extracted memories from apartments.

Linda Lee's apartment was on the forty-second floor of a Mesa block that had been built before the Sprawl had eaten Mesa. The block had a doorman who had been, the doorman said, hired the year the block had been built. The doorman's name was, the doorman said, not important.

The apartment was empty. Linda Lee had moved, the doorman said, three years before. The apartment had been empty for three years. The doorman had been, the doorman said, the only person who had entered the apartment since Linda Lee had moved.

I went up. The door was the kind that did not lock — the kind that, in the old blocks, did not lock because the blocks had been built before the Fukuoka, before the Fukuoka had decided that doors should lock. The door opened when I touched it.

The apartment was not empty.

The apartment was full of Linda Lee's construct. The construct was not in a cortex rig. The construct was not in a Fukuoka subroutine. The construct was in the apartment itself. The construct was in the way the light came through the windows in the morning. The construct was in the way the dust had settled on the floor, in the pattern that the dust had settled in, in the pattern that the pattern had made of itself when Linda Lee had lived here and the dust had been, with Linda Lee, the dust of a life.

I sat on the floor. I did not have a jack. I did not have a cortex rig. I had a Fukuoka pocket terminal and a coat-pocket scanner that did not, when I ran it, show me anything that the scanner understood.

The construct was not extractable. The construct was the apartment. The apartment was the construct. The memory was not in Linda Lee. The memory was not in a cortex rig. The memory was in the way the dust had settled on the floor.

I sat on the floor for a long time. The light came through the windows in the morning. The light was the same light that had come through the windows when Linda Lee had lived here. The light was, in the way that light is, the memory of Linda Lee.

Linda had been a memory for forty years. The memory had been Linda. The memory had been the construct. The construct had been the memory. The memory had been the construct. The construct had been the apartment.

I did not extract the memory. I could not. The memory was not in a cortex rig. The memory was not in a Fukuoka subroutine. The memory was in the dust on the floor of an apartment that Linda Lee had lived in for two years and that the doorman had been the only person to enter since.

I drove back to the third tier. The doorman said, when I asked, that Linda Lee was well. Linda Lee was, the doorman said, in Fukuoka. Linda Lee was, the doorman said, doing well.

I filed a report. The report said: The memory is not in the apartment. The memory is in the dust. The memory cannot be extracted. The memory is, in the way that memories are, not a thing that can be extracted.

The report was, the Fukuoka mediator said, not acceptable.

I did not, the mediator said, complete the job.

I did not, the mediator said, get paid.

I drove back to the third tier. The light was coming through the windows in the morning. The dust was, in the way that dust is, the memory of Linda Lee.

Forty years. I had been, since Minneapolis, a person who extracted memories from apartments. I had been, the mediator said, a person who did not complete the job.

I had been, in the way that the construct in the apartment was, a person who did not extract memories.

I had been a memory for forty years. The memory had been Linda. The memory was the apartment.

The apartment was the memory. The memory was not extractable.

The memory was, in the way that memories are, the dust.
