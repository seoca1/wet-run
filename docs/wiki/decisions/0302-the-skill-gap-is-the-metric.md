# ADR-0302: 스킬 격차 — 두 곡선의 **거리**가 이 게임이 사려던 것

**상태**: Accepted
**날짜**: 2026-11-08
**결정자**: 오너 ("Continue." — ADR-0301 (b))
**우선순위**: P1 (지표) · P2 (검증)
**관련**: [ADR-0301 — Jev 감사](./0301-jev-audited-the-curve.md) · [ADR-0290 — 곡선 재기준화](./0290-the-curve-moves-and-the-core-opens-after-a-path.md) · [ADR-0292 — 드롭은 그 ICE 의 값](./0292-a-drop-is-worth-its-ice.md) · [ADR-0298 — SYPHON](./0298-syphon-a-hot-trace.md)

> ADR-0301 에서 곡선의 모양이 **정책의 함수**라는 것을 확인했다. 그러면 곡선 하나를 목표로 삼는
> 대신, **두 정책의 거리 자체**를 지표로 삼는 편이 정직하다. 이 세션이 산 것은 **선택지**이고,
> 선택지의 값은 **"그걸 쓰는 플레이와 안 쓰는 플레이의 차이"** 로 측정된다.

## 결정 (Decision)

`npm run survival -- --policies` — 두 정책을 **같은 시드로** 돌려 등급별 격차를 출력한다.

- **default**: 지금까지 하네스가 재던 것 — 제안된 **첫 카드**를 받고, 전리품 stop 을 다른 데 쓰지 않음.
- **optimal**: 이 세션의 측정이 찾은 최선 — **가장 쓸모 있는 카드**를 고르고, stop 을 **쓴다**
  (다쳤으면 수리, 흔적이 뜨거우면 vent/burn).
- 경로는 **둘 다 `long`** — 격차가 "어디로 갈까"가 아니라 **"무엇을 고를까"** 만 반영하도록.

## 측정 (Measurement)

24시드 × 53미션:

| 등급 | default | optimal | **격차** |
|---|---:|---:|---:|
| g1 | 100.0 | 100.0 | +0.0 |
| g2 | 76.6 | 98.2 | **+21.6** |
| g3 | 47.3 | 88.3 | **+40.9** |
| g4 | 30.8 | 73.3 | **+42.5** |
| g5 | 11.1 | 47.7 | **+36.6** |
| g6 | 6.9 | 9.7 | **+2.8** |

**평균 +24.1pp · 최대 +42.5pp.**

### 읽는 법

1. **선택지가 실제로 값을 한다**: 중간 등급에서 **+37~42pp**. "아무 카드나 받고 stop 을 안 쓰는"
   플레이와 "고르고 쓰는" 플레이가 **세 배 이상** 차이 난다(g4 30.8 → 73.3).
2. **g1 은 0** — 첫 미션은 선택지가 없어도 되게 설계돼 있다(gate 0, prep 0). 의도된 평평함이다.
3. **g6 는 +2.8** — **최상위 등급에서는 선택지가 거의 무력하다.** 이것은 ADR-0292 가 측정한
   "g6 카드 축 포화"와 ADR-0298 의 "g6 에서 syphon 은 오히려 손해"와 **같은 사실**의 세 번째
   관측이다. g6 는 **덱 빌드가 아니라 생존**의 등급이다.

### 이 지표의 용도

- **회귀 감지**: 변경이 격차를 **크게 줄이면** 선택지를 장식으로 만든 것이다(예: 자동 수리 부활,
  카드 자동 선택). 반대로 **크게 늘리면** 선택을 강제하는 것이다(예: gate 강화) — 둘 다 검토 대상.
- **목표가 아니라 진단**: 절대 수치(+24pp)에 목표를 두지 않는다. **방향과 급변**을 본다.

## 결과 (Consequences)

- **곡선 하나로 판단하지 않게 됐다**: ADR-0301 의 Jev 점수가 정책에 따라 2.54~3.79 로 갈렸던
  문제를, 이 지표가 **"둘 다 재고 거리를 보자"** 로 해소한다.
- **g6 의 빈 곳이 수치로 확인됐다**: 최상위 등급에 **선택지가 통하는 축**이 하나 필요하다
  (카드도 COST 교환도 아님 — 세 번째 축).
- **불변**: 게임 규칙·상수·UI. 하네스에 모드 하나 추가.

## 열린 질문

- **(a) g6 의 세 번째 축.** 격차 +2.8 은 g6 에서 선택지가 무력하다는 뜻이다. 카드(0292)·현상금
  (0293)·COST 교환(0295~0298) 모두 g6 에서는 "고르는 맛"을 못 준다. **g6 전용 축**이 필요하다.
- **(b) `optimal` 의 정의를 고정할 것인가.** 지금은 "현재 최선"이라 시간이 지나면 낡는다.
  고정하면 회귀 비교가 안정되고, 갱신하면 낙관적으로 변한다 — **버전을 붙여 둘 다** 남기는 편이 낫다.
- **(c) 경로 축的分리.** 지금은 둘 다 `long` 이다. `blind` vs `long` 의 격차(싸움 vs 회피)는 또 다른
  지표이고, ADR-0294 가 그걸 ±3.6pp 로 유지하고 있다 — 두 지표를 함께 보면 "무엇을 고를까"와
  "얼마나 싸울까"를 분리해 볼 수 있다.
