# ADR-0312: g6 교전은 얼마나 세게 때려야 하나 — 피해 곡선 스윕

**상태**: Draft (오너 결정 대기)
**날짜**: 2026-11-14
**결정자**: 사용자 (미결 — Jev 는 confidence 0.17 로 값을 정하지 못했다)
**우선순위**: P2 (곡선 · g6)

## 컨텍스트 (Context)

ADR-0307 (b) 는 "g6 교전이 한 턴에 최대 HP 의 28% 이상을 때리는 것이 적절한가"를 열어 두었다.
근거는 **수리 28%(240 중 67)가 3-ICE 방 한 턴(~60)보다 작다**는 것이었고, 그때 측정은
"수리 28% → 0.0%"였다. 즉 **회복이 죽은 선택**이었다.

그 사이 g6 는 두 번 바뀌었다 — ADR-0309(전리품 밖 지급)와 ADR-0311(고유 선택). 그래서
이 ADR 은 **전제를 다시 재고**, 레버의 비용을 측정한다.

**레버**: `ENCOUNTER_DMG_BONUS_PCT_BY_GRADE[5]` (g6 전용, g5 는 자기 값 유지).
ICE 자동공격 = `floor((tier*3 + armor) * (1 + pct/100))`. 현재 g6 밴드 자동공격 17-22, 보스 21.

## 측정 (per-cell, 64시드, `--grade 6`, 최적 정책)

| g6 피해 | g6 미션 | 교전 g6 | 카드만 | 수리만 | 혼합(채택) |
|---|---:|---:|---:|---:|---:|
| **-10 (현재)** | 32.3% | 32.3% | 2.1% | 9.9% | **32.3%** |
| -14 | 33.3% | 42.3% | | | |
| -18 | 34.4% | 52.7% | 3.6% | 15.6% | 34.4% |
| -22 | 35.4% | 59.0% | 4.7% | 20.3% | 35.4% |
| -25 | 37.0% | 79.7% | | | |
| -40 | 46.4% | 92.7% | | | **B1 위반** |
| -55 | 43.2% | 96.0% | | | **B1 위반** |

**g1–g5 는 모든 값에서 byte-identical** — 레버가 g6 전용이고, per-cell 시드(ADR-0310)가
다른 등급의 셀을 움직이지 못하게 막는다.

### 읽기

1. **레버는 계단 함수다.** -22 와 -25 사이에서 교전 승률이 **59.0 → 79.7** 로 뛴다. 매끄러운
   다이얼이 없다.
2. **ADR-0229 B1 이 상한을 정한다.** 교전당 곡선은 단조 비증가여야 하고 g5 가 83.9 이므로
   **-40(92.7)과 -55(96.0)은 위반**이다. 쓸 수 있는 범위는 대략 **-10 ~ -30**.
3. **미션 목표(30, 허용 8pp)는 천천히 소비된다.** -22 가 +3.1pp, -25 가 +4.7pp — 둘 다 통과.
4. **전제가 낡았다.** 오늘의 균형에서 **혼합 정책(32.3%)이 수리만(9.9%)·카드만(2.1%)을
   압도**한다 — 수리는 **살아 있는 선택**이다. g6 를 바꾼 것은 수리가 아니라 **무료 고유**
   (ADR-0309/0311)였다.
5. **피해를 낮추면 모든 전략이 오르고 순서는 그대로다.** 수리는 절대값으로 더 얻지만
   (9.9 → 20.3 at -22) 혼합이 여전히 압도적이다.

## Jev (advisory — 난이도 취향은 ground truth 가 없다)

Choice `keep_-10 / -18 / -22 / -25` = **0.10 / 0.27 / 0.38 / 0.25**, **confidence 0.17**.
질량은 "낮춘다"에 쏠려 있지만(0.90) **값은 결정되지 않았다.** 따라서 자동 변경이 아니라
**오너 결정**이다.

## 고려한 옵션

### Option 1: 유지 (-10)
- **장점**: 목표 여유 +2.3pp 를 지킨다. 수리는 이미 살아 있다(측정 4).
- **단점**: g6 는 여전히 "짧고 치명적"으로 읽힌다 — 회복이 큰 방 한 턴보다 작다.

### Option 2: -18 (cliff 직전)
- **장점**: 교전 승률 52.7% 로 숨통이 트인다. 미션 +4.4pp — 허용 안.
- **단점**: 절벽이 가까워 다음 조정에서 값이 크게 튈 수 있다.

### Option 3: -22 (Jev 최빈값, cliff 직전 마지막 점)
- **장점**: 교전 59.0% · 미션 +5.4pp(허용 안). -25 로 가면 절벽(79.7)이라 그 앞의 마지막 점.
- **단점**: Jev confidence 0.17 — 근거가 약하다. 여유가 +2.3 → **-3.1pp** 로 줄어든다.

### Option 4: -25 (허용 한계)
- **장점**: 교전 79.7% — 체감이 크게 달라진다.
- **단점**: 목표 이탈 +7.0pp 로 허용 8pp 에 붙는다. 절벽 위.

## 추천 (Recommendation)

- **"회복이 의미 있어야 한다"** 가 목표라면 → **측정 4 가 이미 답이다: 지금도 의미 있다.** 변경 불필요.
- **"g6 가 더 길고 패치하며 버티는 싸움이어야 한다"** 가 목표라면 → **-18 또는 -22**
  (절벽 직전), 대가는 목표 여유 4.4~5.4pp. -25 는 허용 안 마지막 값.

## 열린 질문

- **(a) 값은 오너 결정.** Jev 가 값을 정하지 못했다(conf 0.17). 위 표에서 고르면 된다.
- **(b) 절벽.** -22 → -25 에서 교전 승률이 20.7pp 뛴다. 다른 축(HP·방어도)으로 다듬을 여지.
- **(c) 보스는 별개.** `BOSS_HP_BY_GRADE` 는 교전 상한과 분리돼 있다(ADR-0290). 이 스윕은
  보스 피해를 건드리지 않았다 — 보스가 g6 사망의 큰 몫이면 그쪽을 봐야 한다.
