# wet_run — 성장의 순간 연출 시안

## 전제와 연출 원칙

이 문서는 제공된 사실만을 기준으로 작성했다. 카드 획득 연출은 loot 화면의 자기 격자 안에서 끝나야 하며, 매트릭스 도착 연출도 한 화면 계약을 깨지 않는다. 모든 애니메이션은 `main.ts`의 표시 전용 벽시계 상태로 둔다. 리듀서는 카드 획득, HP 회복, 크레딧, 덱 편입 같은 진실만 커밋한다.

공통 규칙:

- `Math.random`을 호출하지 않는다. 파티클 위치와 프레임은 고정된 셀 패턴 또는 카드 인덱스 기반 패턴이다.
- 애니메이션 중에도 숫자키와 ENTER는 언제나 유효하다. 키는 큐잉하지 않고, 현재 표시 상태 위에 즉시 반영한다.
- `reduced-motion`에서는 프레임 변화, 플래시, 이동선, 타이핑 효과를 제거하지만 최종 카드 상태, `ACQUIRED`, HP/크레딧 델타, 매트릭스 HUD 메시지는 남긴다.
- 색은 보조 수단이다. 획득은 `>`, `ACQUIRED`, `[+]`, `DATA` 같은 문자와 형태로도 판독된다.
- 80×50에서는 넓은 중앙 패널을 쓰고, 40×60에서는 패널 폭을 줄이고 세로 스택으로 바꾼다. 어떤 안도 가로 스크롤이나 카메라 이동을 요구하지 않는다.

# 안 1 — TERMINAL COMMIT

## 한 줄 컨셉

카드가 보상으로 “등장”하는 것이 아니라, 기업 터미널이 불완전한 데이터를 강제로 덱에 커밋하는 순간을 보여준다.

## 플레이어가 보는 것

기존 `NEW PROGRAM` 목록은 그대로 유지한다. 카드 선택 직후 선택 카드 한 장에만 고정된 3단계 표시가 발생한다.

### 80×50 목업

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ DATA SALVAGE                                             LOOT                 │
│ ─────────────────────────────────────────────────────    1-3: card             │
│ HP 78/100       +4,075 credits       NEW PROGRAM                              │
│                                                                              │
│        ┌────────────────────────────────────────────────────────┐            │
│        │ PROGRAM SLOT 01                                        │            │
│        │                                                        │            │
│        │ > 1 KRAKEN                                             │            │
│        │   [PIERCE 2]  [ICE TRACE]                              │            │
│        │                                                        │            │
│        │   DATA LINK ............ OPEN                          │            │
│        │   SIGNATURE ............ KRAKEN                        │            │
│        │   DECK COMMIT ......... [##########] 100%              │            │
│        │                                                        │            │
│        │   [+] PROGRAM ACQUIRED                                 │            │
│        └────────────────────────────────────────────────────────┘            │
│                                                                              │
│  2 INSPIRE       [SHIELD 2]              3 DECRYPT       [SCAN 1]            │
│  1-3: take a card  |  ENTER: continue                                      │
└──────────────────────────────────────────────────────────────────────────────┘
```

`[##########]`은 0%, 33%, 66%, 100% 네 고정 단계만 사용한다. 100%에 도달한 뒤에는 프레임을 반복하지 않고 현재 화면에 머문다. 따라서 ENTER가 입력되기 전까지 “획득이 끝났는지”가 명확하다.

### 40×60 목업

```text
┌──────────────────────────────────────┐
│ DATA SALVAGE                 LOOT    │
│ HP 78/100                  1-3 card  │
│                                      │
│ ┌──────────────────────────────────┐ │
│ │ PROGRAM SLOT 01                  │ │
│ │                                  │ │
│ │ > 1 KRAKEN                       │ │
│ │   [PIERCE 2]                     │ │
│ │   [ICE TRACE]                    │ │
│ │                                  │ │
│ │ LINK OPEN                        │ │
│ │ SIGNATURE: KRAKEN                │ │
│ │ COMMIT [##########] 100%         │ │
│ │                                  │ │
│ │ [+] ACQUIRED                     │ │
│ └──────────────────────────────────┘ │
│                                      │
│ 2 INSPIRE [SHIELD 2]                │
│ 3 DECRYPT [SCAN 1]                  │
│                                      │
│ ENTER: continue                     │
└──────────────────────────────────────┘
```

## 소리와 타이밍

- `0ms`: 숫자키 입력, 선택 카드의 `>`와 `PROGRAM SLOT` 표시. `SFX_IDS.EQUIP` 재생.
- `0–90ms`: `DATA LINK ............ OPEN`만 밝게 표시.
- `90–220ms`: 커밋 바가 33% → 66% → 100%으로 바뀐다. 별도 입력 잠금 없음.
- `220–420ms`: `SIGNATURE`와 `[+] PROGRAM ACQUIRED`가 최종 상태로 남는다. 화면은 계속 대기.
- ENTER: 매트릭스로 즉시 전환. 추가 대기 없음.

전체 연출 표시 시간은 약 420ms지만, 사용자는 언제든 ENTER로 진행할 수 있다.

## 재사용과 신규 구현

재사용: `SFX_IDS.EQUIP`, 기존 카드 선택/흐림/`ENTER: continue` 흐름, 카드 효과 태그, 기존 HP/크레딧 진실값.

신규: `lootCommitFrame` 같은 표시 전용 상태와 카드 인덱스별 고정 커밋 단계. 새 이벤트 버스, 새 리듀서 상태, 저장 큐는 필요 없다. 전투 밖에서 `data_acquired`를 직접 합성하지 않으므로 기존 VFX 시스템의 전투 전용 제약도 건드리지 않는다.

## reduced-motion

사라짐: 커밋 바의 단계 변화와 420ms의 점진적 등장.

남음: 선택 카드의 `>`, `PROGRAM SLOT`, `LINK OPEN`, `COMMIT 100%`, `[+] PROGRAM ACQUIRED`, 기존 HP/크레딧 델타와 ENTER 안내.

## 비용과 리스크

**비용: 작음.** 텍스트 프레임 4개와 표시 전용 시간값만 필요하다.

리스크는 낮다. 바가 실제 덱 편입을 약속하는 것처럼 보이므로, 카드 선택 진실 커밋 이후에만 이 화면을 시작해야 한다. 이 순서만 지키면 어포던스 진실성 문제가 없다.

**확신: 높음.** 제공된 입력 흐름과 한 화면 계약에 가장 직접적으로 맞는다.

# 안 2 — GHOST TRACE

## 한 줄 컨셉

획득한 프로그램이 카드 목록에서 덱으로 이동하는 대신, 고정된 “데이터 흔적”을 남기며 HUD의 기록으로 승격된다.

## 플레이어가 보는 것

실제 카드 이동 애니메이션은 하지 않는다. 카드가 화면 좌표를 가로질러 날아가거나 다른 UI를 따라가는 것은 작은 레이아웃에서 겹침을 만들기 쉽기 때문이다. 대신 선택 행의 좌측에 `>`가 생기고, 같은 행에서 오른쪽으로 고정된 ASCII 연결선이 짧게 나타난다.

### 80×50 목업

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ DATA SALVAGE                                             LOOT                 │
│ HP 78/100       +4,075 credits       NEW PROGRAM         1-3: card            │
│                                                                              │
│  > 1 KRAKEN      [PIERCE 2]  ──╼  DECK[07]  [ACQUIRED]                      │
│    2 INSPIRE     [SHIELD 2]      DECK[--]                                   │
│    3 DECRYPT     [SCAN 1]        DECK[--]                                   │
│                                                                              │
│                    . . . . . . . . . . . .                                  │
│                    DATA RESIDUE: KRAKEN                                     │
│                                                                              │
│  + PROGRAM COMMITTED                    ENTER: continue                    │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 40×60 목업

```text
┌──────────────────────────────────────┐
│ DATA SALVAGE                 LOOT    │
│ HP 78/100                  1-3 card  │
│                                      │
│ > 1 KRAKEN                           │
│   [PIERCE 2]                         │
│       │                              │
│       └─╼ DECK[07]                   │
│          [ACQUIRED]                  │
│                                      │
│ 2 INSPIRE [SHIELD 2]                │
│ 3 DECRYPT [SCAN 1]                  │
│                                      │
│ DATA RESIDUE: KRAKEN                │
│ + PROGRAM COMMITTED                 │
│                                      │
│ ENTER: continue                     │
└──────────────────────────────────────┘
```

## 소리와 타이밍

- `0ms`: `SFX_IDS.EQUIP`, 행 강조.
- `0–160ms`: 80×50에서는 연결선이 `─` → `──` → `──╼`로 늘어난다. 40×60에서는 세로 `│`와 `└─╼`가 세 단계로 그려진다.
- `160–300ms`: `DECK[07]`과 `[ACQUIRED]`를 표시한다. `07`은 실제 덱 슬롯이 알려진 경우에만 표시한다. 슬롯값을 알 수 없다면 `DECK`로 표시하고 숫자를 만들지 않는다.
- `300ms 이후`: `DATA RESIDUE`와 `PROGRAM COMMITTED`를 유지한다.

## 재사용과 신규 구현

재사용: `SFX_IDS.EQUIP`, 기존 `ACQUIRED` 상태, 카드 효과 태그, 상태 효과의 색+글리프+텍스트 원칙.

신규: `ghostTraceFrame` 표시 전용 시간값과 두 레이아웃용 연결선 템플릿. 실제 덱 슬롯을 표시할 수 없는 경우 숫자를 표시하지 않는 분기 필요. `vfxInstances`에는 넣지 않는다.

## reduced-motion

사라짐: 선이 자라는 과정.

남음: 카드 행의 `>`, 정적 `╼ DECK`, `[ACQUIRED]`, `DATA RESIDUE`, `PROGRAM COMMITTED`. 40×60에서는 세로 최종 연결선만 남긴다.

## 비용과 리스크

**비용: 중간.** 가로형/세로형 레이아웃 분기와 폭 계산이 필요하다.

리스크는 중간이다. `DECK[07]`이 실제 상태와 불일치하면 하드 제약 1을 위반한다. 실제 슬롯 정보가 제공되지 않는다면 숫자 없는 `DECK LINK`만 사용해야 한다. 카드가 실제로 화면을 이동한다고 오해되지 않도록 연결선을 짧고 정적으로 유지해야 한다.

**확신: 중간.** ASCII 매체에는 잘 맞지만, 덱 슬롯 진실값을 노출할 수 있는지 추가 확인 없이 숫자를 넣을 수 없다.

# 안 3 — COLD BOOT / PROGRAM WAKE

## 한 줄 컨셉

새 카드를 얻는 것은 보물 상자가 열리는 일이 아니라, 낡은 기업 시스템에서 프로그램이 차갑게 부팅되는 사건이다.

## 플레이어가 보는 것

선택 카드의 효과 태그 하나가 짧은 상태 글리프로 재표현된다. 예를 들어 `PIERCE 2`는 `[P2]`, `SHIELD 2`는 `[S2]`로 보인다. 이것은 새 게임플레이 상태를 추가하는 것이 아니라 기존 효과 태그의 표시적 축약이다.

### 80×50 목업

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ DATA SALVAGE                                             LOOT                 │
│ HP 78/100       +4,075 credits       NEW PROGRAM         1-3: card            │
│                                                                              │
│          [ PROGRAM WAKE / KRAKEN ]                                          │
│          ┌──────────────────────────────────────────────┐                    │
│          │  [P2]  [ICE TRACE]                           │                    │
│          │                                               │                    │
│          │  BOOT  ....  ....  ....  READY                │                    │
│          │  > KRAKEN                                    │                    │
│          │  [+] ACQUIRED                                │                    │
│          └──────────────────────────────────────────────┘                    │
│                                                                              │
│  2 INSPIRE [SHIELD 2]     3 DECRYPT [SCAN 1]                                 │
│  ENTER: continue                                                               │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 40×60 목업

```text
┌──────────────────────────────────────┐
│ DATA SALVAGE                 LOOT    │
│ HP 78/100                  1-3 card  │
│                                      │
│       PROGRAM WAKE                  │
│       [KRAKEN]                      │
│                                      │
│       [P2] [ICE TRACE]              │
│       BOOT ... READY                │
│       > ACQUIRED                    │
│                                      │
│ 2 INSPIRE [SHIELD 2]                │
│ 3 DECRYPT [SCAN 1]                  │
│                                      │
│ ENTER: continue                     │
└──────────────────────────────────────┘
```

## 소리와 타이밍

- `0ms`: `SFX_IDS.EQUIP`.
- `0–80ms`: `PROGRAM WAKE` 라벨과 카드명이 나타난다.
- `80–260ms`: `BOOT .... .... .... READY`의 점 그룹이 고정 단계로 치환된다. 타이핑 커서나 깜박이는 커서는 쓰지 않는다.
- `260ms 이후`: `[+] ACQUIRED`와 효과 태그를 유지한다.
- ENTER는 언제나 즉시 매트릭스로 돌아간다.

도착 순간에는 매트릭스의 현재 노드 옆 HUD에 다음처럼 한 번의 정적 상태 보고를 보탠다.

```text
ROUTE READY
KRAKEN ONLINE // HP 78/100
CHOOSE ADJACENT ROUTE
```

이 메시지는 기존 `Took Kraken. Choose an adjacent route — healed to 78/100`의 의미를 바꾸지 않고, 줄바꿈 가능한 폭으로 재배치한 것이다.

## 재사용과 신규 구현

재사용: 기존 효과 태그, 상태 효과의 글리프+텍스트 표기 관행, `SFX_IDS.EQUIP`, 기존 HUD 메시지와 실제 HP 값.

신규: `programWakeFrame` 표시 전용 단계와 40×60에서의 세로 축약 문구. 효과 태그를 임의로 바꾸지 않도록 축약표는 기존 태그에서 결정적으로 파생해야 한다. 새 상태 효과나 새 타겟 메커니즘은 추가하지 않는다.

## reduced-motion

사라짐: 부팅 단계 전환.

남음: `PROGRAM WAKE`, 카드명, 실제 효과 태그, `BOOT READY`, `[+] ACQUIRED`, 매트릭스의 `ROUTE READY`와 실제 HP/카드명 메시지.

## 비용과 리스크

**비용: 중간.** 기존 태그의 좁은 화면 표기와 HUD 줄바꿈을 설계해야 한다.

리스크는 낮음에서 중간이다. `ONLINE`이 실제로 사용 가능한 카드라는 뜻으로 읽힐 수 있으므로, 리듀서가 덱 편입을 커밋한 뒤에만 보여야 한다. `READY`는 부팅 애니메이션의 종료를 뜻하고 입력 대기를 뜻하지 않도록 ENTER 안내를 계속 표시한다.

**확신: 높음.** 깁슨식 기업 터미널 톤과 가장 잘 맞으며, 색을 걷어내도 상태가 읽힌다.

# 안 4 — ARRIVAL: ROUTE HANDOFF

## 한 줄 컨셉

성장의 순간을 loot 화면에만 가두지 않고, 매트릭스에 돌아온 뒤 “새 프로그램을 가진 데커가 다시 네트워크에 접속했다”는 도착 사건으로 마무리한다.

## 플레이어가 보는 것

카드 획득 화면에서는 기존의 `ACQUIRED`를 최소한으로 유지한다. ENTER 후 매트릭스에 복귀할 때, 플레이어 경로가 도착한 노드 주변에 220ms의 기존 `matrixTravelFrame`과 구별되는 짧은 정착 표시를 한 번 보여준다. 카메라는 움직이지 않는다. 노드만 현재 보드 안에서 강조된다.

### 80×50 목업

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ ICE MATRIX                                                  HP 78/100         │
│                                                                              │
│        [ICE]──────[DATA]──────[ICE]                                        │
│                    │                                                         │
│               ┌────▼────┐                                                    │
│               │  YOU    │  + PROGRAM: KRAKEN                                │
│               │  [P2]   │  ROUTE HANDOFF                                   │
│               └────┬────┘                                                    │
│                    │                                                         │
│             [LOCK]─┴─[ICE]                                                    │
│                                                                              │
│ HUD  Took Kraken. Choose an adjacent route — healed to 78/100               │
│      [ROUTE HANDOFF COMPLETE]                                                │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 40×60 목업

```text
┌──────────────────────────────────────┐
│ ICE MATRIX                 HP 78/100 │
│                                      │
│       [ICE]                          │
│         │                            │
│ [DATA]──▼──[ICE]                    │
│       ┌──────┐                      │
│       │ YOU  │                      │
│       │ [P2] │                      │
│       └──┬───┘                      │
│          │                          │
│        [LOCK]                       │
│                                      │
│ + PROGRAM: KRAKEN                   │
│ ROUTE HANDOFF COMPLETE              │
│                                      │
│ Choose an adjacent route             │
└──────────────────────────────────────┘
```

## 소리와 타이밍

- loot에서 숫자키 입력 시 기존 `SFX_IDS.EQUIP`.
- ENTER 후 기존 `matrixTravelFrame` 220ms를 재사용.
- `220–360ms`: 도착 노드에 고정된 `+ PROGRAM: KRAKEN`과 `[ROUTE HANDOFF COMPLETE]` 표시. 이동·카메라·스크롤 없음.
- `360ms 이후`: 기존 HUD 메시지 유지. 다음 경로 선택 입력은 즉시 유효하다.

도착 연출은 카드 획득 순간의 대체물이 아니라, 카드 선택과 매트릭스 복귀 사이의 인과를 읽히게 하는 후속 박자다.

## 재사용과 신규 구현

재사용: `matrixTravelFrame` 220ms, 기존 매트릭스 노드와 경로 표시, 기존 HUD 메시지, `SFX_IDS.EQUIP`은 loot에서만 재생.

신규: `matrixArrivalFrame` 표시 전용 상태와 현재 도착 노드의 기존 위치를 강조하는 고정 문자 프레임. 새 VFX 종류는 필요하지 않다. `vfxInstances`에 넣지 않고 매트릭스 렌더링 계층에서 합성한다.

## reduced-motion

사라짐: 도착 노드의 강조 단계와 220ms 이동 프레임.

남음: `+ PROGRAM: KRAKEN`, `[ROUTE HANDOFF COMPLETE]`, 기존 HUD의 카드명·실제 HP·인접 경로 선택 안내.

## 비용과 리스크

**비용: 작음에서 중간.** 매트릭스 도착 좌표와 두 레이아웃에서의 짧은 라벨 배치를 계산해야 한다.

리스크는 낮음이다. 다만 카드 획득 후 매트릭스에 복귀할 때 표시 전용 상태를 초기화하지 않으면 다음 노드에서도 메시지가 남을 수 있다. 표시 상태는 저장하지 않고, 매트릭스 진입과 동시에 시작·종료되어야 한다.

**확신: 높음.** 사용자가 요청한 “성장이 매트릭스로 이어지는 도착 순간”을 가장 정확히 다룬다.

# 추천 순위

## 1위 — TERMINAL COMMIT + ARRIVAL: ROUTE HANDOFF

가장 추천한다. 두 안을 하나의 작은 흐름으로 결합하면 다음의 3박자가 된다.

1. **커밋:** `PROGRAM SLOT`, `COMMIT 100%`, `[+] ACQUIRED`로 카드가 실제 덱에 들어갔다는 사건을 보여준다.
2. **확인:** ENTER는 즉시 유효하며 매트릭스로 돌아간다.
3. **인수인계:** 도착 노드에서 `+ PROGRAM: KRAKEN`과 `ROUTE HANDOFF COMPLETE`로 새 성장과 다음 경로 선택을 연결한다.

이 조합은 새 VFX 종류나 새 이벤트 버스 없이 구현 가능하고, 전투 밖 VFX 합성 제약을 건드리지 않는다. “화려한 보상”이 아니라 “기업 시스템에 비인가 프로그램을 강제로 등록하는 일”처럼 보여서 1980년대 깁슨 톤에도 맞는다. 재미는 색 변화가 아니라 상태가 단계적으로 확정되고, 그 결과가 다음 화면의 경로 선택 능력으로 즉시 이어진다는 데서 나온다.

**확신: 높음.**

## 2위 — COLD BOOT / PROGRAM WAKE

가장 강한 분위기 안이다. `BOOT`, `READY`, 상태 글리프는 ASCII 캔버스와 차가운 기업 터미널에 잘 맞는다. 다만 좁은 40×60 레이아웃에서 문구를 줄여야 하고, `READY`의 의미를 실제 사용 가능 상태와 혼동하지 않도록 주의해야 한다.

**확신: 높음.**

## 3위 — GHOST TRACE

획득과 덱 편입의 관계를 가장 직관적으로 표현한다. 그러나 화면에 실제 덱 슬롯 숫자를 표시하려면 그 값이 제공되어야 한다. 없는 값을 만들어내지 않는다는 하드 제약 때문에, 슬롯 숫자 없는 버전으로 제한하면 시각적 임팩트가 줄어든다.

**확신: 중간.**

## 4위 — 안 1 단독 또는 기존 방식의 강화

단독으로는 안전하지만 덜 사건처럼 느껴진다. 따라서 `TERMINAL COMMIT`은 `ARRIVAL: ROUTE HANDOFF`와 결합할 때 가치가 커진다.

**확신: 높음.**

# 이건 만들지 마라

## 1. 카드가 화면을 가로질러 날아가 HUD에 꽂히는 연출

40×60에서 폭이 부족하고, 가로 스크롤·겹침·카메라 이동을 유발한다. 카드 위젯이나 드래그 은유도 요구사항의 금지 목록과 충돌한다. 고정된 ASCII 연결선으로만 대체한다.

## 2. VFX가 끝날 때까지 입력을 막는 연출

`data_acquired` 또는 새 파티클을 재생한 뒤 ENTER를 기다리게 하는 방식은 입력 락과 입력 대기 금지를 동시에 위반한다. 애니메이션은 장식이고, ENTER는 언제나 전환을 수행해야 한다.

## 3. 전투용 `data_acquired`를 그대로 loot 화면에 주입하는 방식

현재 전투 화면 경로에서만 VFX 합성이 된다는 사실과 충돌한다. 렌더러를 공유하도록 순수 표시 함수를 분리하는 별도 작업 없이, loot 화면에 `vfxInstances`를 억지로 연결하면 화면별 렌더 계약이 흐려진다.

## 4. 랜덤 파티클, 랜덤 글리치, 랜덤 카드 미리보기

연출 때문에 RNG를 소비하거나, 피해·효과를 미리 계산하는 것은 byte-identical 밸런스 제약을 위반할 수 있다. 모든 패턴은 고정 프레임과 카드 인덱스 기반으로 만든다.

## 5. 축하 폭죽, 금색 별, 레벨업 게이지, 콤보 팡파르

밝은 축제와 유치한 반짝임은 깁슨 톤을 깨뜨린다. 금색은 이미 `data_acquired`의 기존 언어가 있으므로 쓰더라도 짧은 기업 경고등 수준의 한정된 강조로만 사용한다.

## 6. 실제로 존재하지 않는 덱 슬롯, 프로그램 레벨, 희귀도, 새 상태 효과

`DECK[07]`, `LV.2`, `RARE`, `ONLINE` 같은 값은 근거가 있을 때만 표시한다. 제공된 상태에 없는 권위값은 화면을 더 풍부하게 보이게 할 수 있어도 어포던스 진실성을 훼손한다.

## 7. Y/N 확인창 또는 “축하 메시지를 닫기 위한” 추가 단계

현재 계약은 숫자키로 카드 선택, ENTER로 계속이다. 새 확인 단계는 성장의 리듬을 늘어뜨리고 금지된 Y/N 문법과 충돌한다.

# 최종 구현 시 권장 표시 상태

리듀서에 새 상태를 추가하지 않고 `main.ts` 표시 전용 계층에 다음 정도만 둔다.

```text
lootCommitFrame: { startedAtMs, cardIndex } | null
matrixArrivalFrame: { startedAtMs, cardName } | null
```

각 프레임은 벽시계 delta로만 계산한다. 카드 획득 reducer action이 성공한 직후 `lootCommitFrame`을 시작하고, ENTER가 처리되면 loot 표시 상태를 지운 뒤 매트릭스 진입 시 `matrixArrivalFrame`을 시작한다. 애니메이션이 끝났다는 신호를 reducer로 보내지 않는다. 프레임 종료는 렌더링 시각 비교로만 판단한다.

추천 최종 문구:

```text
loot:
> 1 KRAKEN  [PIERCE 2]  [ICE TRACE]
PROGRAM SLOT: COMMITTED
[+] PROGRAM ACQUIRED
ENTER: continue

matrix HUD:
Took Kraken. Choose an adjacent route — healed to 78/100
[ROUTE HANDOFF COMPLETE]
```

이 구성은 성장의 결과값을 바꾸지 않으면서도, 플레이어가 “카드를 선택했다”가 아니라 “비인가 프로그램을 덱에 커밋했고, 그 프로그램을 가진 채 네트워크로 복귀했다”고 느끼게 한다.
