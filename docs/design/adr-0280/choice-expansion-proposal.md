# 플레이어 선택지 확대 제안 — g5·g6 를 "선택"으로 푼다

> 오너 지시: *"사용자의 선택지를 늘리는 방식으로 개선하고 싶어. 영향도가 커도 상관없어.
> 몰입도도 높아야 해."*
> 근거: ADR-0280 §6·§8·§9 — g5·g6 는 **회복·곡선·덱 강도** 어느 것으로도 안 열린다(네 방향 확인).
> 남은 것은 **미션의 모양**이고, 그건 플레이어가 고르게 할 수 있다.

## 왜 "선택지"가 이 문제의 정답인가

측정이 말하는 g5·g6 의 구조:

- 교전 승률 ~41%(신선한 만피 기준) × **7.4교전** → 완주율 ~0.
- g4–g6 에서 러너는 **첫 교전에서 죽는다**(0.6–0.8교전/런) → 카드 보상을 **한 번도 못 받는다**.
- 즉 **"이기려면 카드가 필요한데, 카드를 받으려면 이겨야 한다"** 는 교착.

숫자를 조여서 풀 수 없다는 것이 네 번 확인됐으므로, 남은 자유도는 **플레이어가 런의 조건을 고르는 것**이다.
그리고 이 게임에는 이미 그 재료가 있다 — **매트릭스 분기 경로**다. 측정 버그가 우연히 증명했다:
`0 → 2 → 5` 로 **교전을 건너뛸 수 있다**. 다만 지금은 그 선택이 **보이지도, 값을 매기지도 않는다.**

## 제안 A — 경로 선택을 "런 설계"로 만든다 (권고)

**무엇:** 분기마다 각 경로가 무엇을 주고 무엇을 요구하는지 **보이게** 하고, 경로가 런의 모양을 정하게 한다.

- 경로 카드에 표시: `교전 수 · 예상 난도(등급 대비) · 보상(카드/크레딧/재료)`.
- 그래서 플레이어가 고른다: **"3교전으로 덱을 키운다" vs "1교전으로 빨리 끝낸다."**
- g5·g6 처럼 긴 미션은 자연히 **"짧고 얇은 길"이 생긴다** — 그리고 그게 §8 의 "미션 길이" 문제를
  **플레이어의 결정으로** 푼다(콘텐츠를 지우지 않고).

**왜 몰입도가 오르나:** 잭인 전에 경로를 계획하는 것은 스프롤의 실제 행동이다 — 무엇을 건드리고
무엇을 피할지. 지금은 그 결정이 **우연히** 일어나고(내 봇이 그렇게 했다) 플레이어는 모른다.

**영향도:** 매트릭스 렌더 + 경로 메타데이터(교전 수는 이미 계산 가능) + 문구. **리듀서·저장 스키마 무변경.**

**검증 방법:** `npm run survival` 에 "최단 경로 정책"을 추가해 **체감 난도 상한/하한**을 측정한다.

## 제안 B — 전리품 화면을 진짜 선택으로 (보상 축 확대)

**무엇:** 지금 전리품 화면은 **카드 1장 또는 ENTER 로 건너뛰기**뿐이고 회복은 **자동**이다.
이걸 **택1**로 바꾼다: `프로그램 1장` / `수리(회복)` / `크레딧·재료`.

- 회복이 **자동에서 선택으로** 바뀌므로, ADR-0280 §6 의 회복 수치가 플레이어 손에 들어간다.
- 첫 교전에서 죽는 문제(g4–g6)에 **교전 전 준비**라는 선택이 생긴다.
- **몰입도:** "지금 뭘 챙겨야 하나"는 매 교전 반복되는 결정이다.

**영향도:** 전리품 화면 UI + 리듀서 분기 + 테스트. **저장 스키마 무변경**(선택 결과는 기존 필드로 표현 가능).
**대가:** 회복이 선택이 되면 실질 회복량이 줄어 g3·g4 가 다시 어려워질 수 있다 — 재측정 필요.

## 제안 C — 잭인 전 준비(로드아웃) 선택

**무엇:** 런 시작 전에 **크레딧으로 준비**한다(카드 구매 / 장비 / 정보). 지금 `credits` 는
쓰임이 없다(`purchaseItem` 호출자 0).

- g4–g6 의 진짜 병목(**첫 교전**)에 정면으로 대응한다.
- **몰입도 최상:** 픽서의 브리핑 → 장비 사기 → 잭인. 스프롤 톤 그대로.
- **영향도 최대:** 새 화면 + 경제 배선 + 저장 스키마(로드아웃).

**대가:** 가장 큰 작업. 그리고 "크레딧이 곧 덱 강도"가 되면 미션 간 난이도 곡선을 다시 봐야 한다.

## 제안 D — 교전 중 선택 (도주·아이템)

교전에서 **JACK OUT** 은 지금 런 포기다. 대신 **"물러난다"**(교전을 남겨두고 HP 를 잃으며 후퇴)나
**아이템 사용**을 주면 매 교전이 결정이 된다. g4–g6 의 첫 교전 교착을 직접 푼다.
대가는 아이템/인벤토리(저장 스키마).

## 권고

**A → B → (필요하면) C 순서.**

- **A** 는 리듀서·스키마를 건드리지 않고 **§8 의 "미션 길이" 문제를 플레이어 선택으로** 옮긴다.
  가장 싸고, 이 게임에 이미 있는 것(분기 경로)을 **보이게** 만들 뿐이다.
- **B** 는 회복을 선택으로 바꿔 §6 의 수치를 플레이어에게 넘긴다. A 다음에 자연스럽다.
- **C** 는 가장 강력하지만 가장 크다. A·B 로 부족할 때가 맞다.

**A 를 먼저 하는 이유는 측정으로 확인된다:** A 를 넣으면 `npm run survival` 에
**"최단 경로"와 "최장 경로" 두 정책**을 넣어 상한·하한을 잴 수 있고, 그것이 곧 "선택이 얼마나
영향을 주는가"의 답이다. 선택이 난도를 못 바꾸면 A 는 실패한 것이고, C 로 가야 한다.
