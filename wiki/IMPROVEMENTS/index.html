    Cyberspace generator O(n²) → O(n) (ADR-0060)¶

    • 이전: for i, n in enumerate(nodes): if n.id == c ICE enforcement
    • 이후: _index_nodes_by_id(nodes) dict lookup (O(1))
    • 효과: 미션 생성 ~3초 → <0.1초
