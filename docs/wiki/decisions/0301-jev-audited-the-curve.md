# ADR-0301: Jev 로 곡선을 감사했다 — 곡선의 모양은 **정책에 달려 있다**

**상태**: Accepted (감사 기록 + 도구)
**날짜**: 2026-11-08
**결정자**: 오너 ("jev ai 도움 받아서 더 진행해봐")
**우선순위**: P2 (검증 도구) · P2 (기준선)
**관련**: [ADR-0290 — 곡선 재기준화](./0290-the-curve-moves-and-the-core-opens-after-a-path.md) · [ADR-0294 — 처치는 흔적을 남긴다](./0294-every-kill-leaves-a-trace.md) · [ADR-0298 — SYPHON](./0298-syphon-a-hot-trace.md)

> 오너가 **Jev(System One)를 붙여** 더 진행하라고 했다. Jev는 곡선의 **형태**를 0~5로 채점하는
> 결정 모델(WF8)이다. 두 곡선을 채점했더니 **점수가 2.54 / 3.09 / 3.79 로 갈렸고**, 그 차이가
> **"어느 정책으로 잰 곡선인가"** 때문이라는 것을 확인했다.

## 측정 (Measurement)

### 1. 교전당 곡선 (오프닝 덱, `npm run balance`, 300런)

`100.0 / 100.0 / 100.0 / 99.1 / 82.2 / 33.3`

```
Jev score = 2.54 / 5   confidence 0.52
  p(level 2)=0.36  p(level 3)=0.51  p(level 4)=0.05
```

**지적**: 상단(g1-g3)이 **평평**하다. 실제로 손잡이를 재봤다 — `ENCOUNTER_DMG_BONUS` 를
`50/30/−32` → `50/50/+5` 로 흔들어도 **곡선이 한 자리도 안 움직였다**(계단 함수라 g1-g3 에서 무효).
즉 **오프닝 덱이 한 교전을 반드시 이기는 구조**이고, 이 곡선은 **플레이어 경험이 아니다.**

### 2. 미션 곡선 — **강한 정책**(`--loot smart --cards best`, 48시드)

`100.0 / 98.0 / 85.6 / 76.7 / 40.0 / 14.6`

```
Jev score = 3.09 / 5   confidence 0.48  (낮음)
```

**지적**: **g4 → g5 절벽**(76.7 → 40.0). 완화를 시도했다:

| 손잡이 | g5 싸움 | g5 회피 | 격차 |
|---|---:|---:|---:|
| 현재 | 40.0 | 43.3 | **3.3** |
| prep HP 250 | 44.7 | 52.1 | 7.4 |
| prep HP 280 | 58.8 | 65.3 | 6.5 |
| 보스 HP 145 | 57.4 | 70.8 | **13.4** |
| 보스 HP 125 | 68.5 | 84.0 | **15.5** |

**모든 완화가 "회피"를 더 이롭게 만든다.** 이유: 완화는 **HP 여유**를 늘리는데, 회피 전략은
HP 말고 쓸 수단이 없고 싸움 전략은 카드로 이미 여유를 벌어 놓았기 때문이다. **즉 g5 절벽은
전략 균형을 지탱하는 부품**이고, 부드럽게 만들면 이 세션이 세운 거래(±3.6pp)가 깨진다.

### 3. 미션 곡선 — **기본 정책**(하네스 기본값, 24시드)

`100.0 / 76.6 / 47.3 / 30.8 / 11.1 / 6.9`

```
Jev score = 3.79 / 5   confidence 0.83   ← 최고점
```

**매끄러운 경사**이고 단조 감소, 스프레드도 충분 — Jev 가 가장 좋아한 형태다. 대가로 **난이도가
훨씬 높다**(g3 47.3%). 즉 **곡선의 모양은 정책의 함수**다: 최적 플레이는 상단을 눌러 평평하게
만들고 끝에 절벽을 만들며, 평범한 플레이는 완만한 경사를 만든다.

## 결정 (Decision)

1. **곡선을 "고치지" 않는다.** Jev 점수를 올리는 손잡이(prep·보스 HP)는 **전략 균형을 깨는 것으로
   측정됐다**(격차 3.3 → 6.5~15.5pp). 오너의 우선순위는 **선택지**이고, 그 균형이 이 세션의 성과다.
2. **감사 도구를 남긴다** — `scripts/jev-difficulty.sh` 에 **`--curve mission`** 을 추가했다.
   지금까지 이 스크립트는 **교전당 곡선만** 채점했는데, 그건 플레이어 경험이 아니다.
   ```bash
   scripts/jev-difficulty.sh --curve mission --seeds 24
   ```
3. **두 곡선을 함께 본다**: 교전당은 "오프닝 덱이 그 등급의 싸움을 이기나", 미션은 "플레이어가
   그 등급을 완주하나". 한쪽만 보면 **평평한 상단**이나 **가짜 절벽**을 진짜로 착각한다.

## 결과 (Consequences)

- **외부 감사 흔적**: 세 번의 Jev 호출(2.54 / 3.09 / 3.79)과 각각의 신뢰도가 남았다.
  신뢰도가 낮은(0.48) 점수는 **판단 근거로 쓰지 않았다** — WF8 정책(advisory)을 그대로 지켰다.
- **도구가 프로젝트에 남았다**: 다음 세션은 `--curve mission` 으로 **플레이어 경험 곡선의 드리프트**를
  볼 수 있다.
- **불변**: 게임 규칙·상수·UI. 이 ADR 은 **감사와 도구**다.

## 열린 질문

- **(a) 기본 정책의 난이도.** Jev 가 가장 좋아한 곡선(3.79)은 **g3 47.3%** 로 상당히 가혹하다.
  "평범한 플레이"의 기준선을 어디로 둘지(하네스 기본값이 그 기준선인지) 정해야 한다.
- **(b) 정책별 곡선을 모두 기록할 것인가.** `--curve mission` 은 기본 정책만 잰다. `--loot smart`
  같은 최적 정책도 플래그로 노출하면 **두 곡선의 격차 자체**를 지표로 쓸 수 있다.
- **(c) Jev 임계값.** WF8 은 advisory 라 실패로 만들 수 없다. 곡선 점수를 **회귀 게이트**로 쓰려면
  골드셋을 이 프로젝트 기준으로 다시 만들어야 한다(현재 골드셋은 일반 곡선용).
