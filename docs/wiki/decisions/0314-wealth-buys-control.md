# ADR-0314: 부는 지배를 산다 — control 엔딩은 구조적으로 죽어 있었다

**상태**: Accepted
**날짜**: 2026-11-15
**결정자**: AI 위임 (오너 "추천대로 해줘" — 경제 축 #2)
**우선순위**: P1 (엔딩 · 경제)

## 컨텍스트 (Context)

경제 축(#2)의 질문은 "크레딧이 아무것도 못 산다"였다. 그런데 소비처를 만들기 전에
**이미 있는 소비처**를 확인했더니, `control` 엔딩의 게이트가 죽어 있었다:

```ts
if (hpPct > 0.75 && ctx.credits > 5000) return control;
```

`npm run endings` 는 0/53 을 보고했지만, 그건 한 시드의 표본 문제로 보였다. 아니다.

## 측정 (per-cell, 64시드, 3392런, 최적 정책, 엔딩 2330건)

| 조건 | 엔딩 수 | 비율 |
|---|---:|---:|
| `credits > 5000` | 260 | 11.2% |
| `hp > 75%` | 419 | 18.0% |
| **둘 다** | **0** | **0.0%** |

- 엔딩 시점 HP%: p10 **9** · p50 **39** · p90 87 · max 97
- 등급별 평균 크레딧: g1 2,069 · g2 2,815 · g3 3,723 · g4 4,717 · **g5 7,546 · g6 8,762**

**두 조건은 구조적으로 반상관이다.** 크레딧은 **싸워서** 벌고(처치 현상금, ADR-0293),
싸우면 **HP를 쓴다.** 부자가 되는 런이 곧 다친 런이다. 그래서 절대 겹치지 않는다.

### 대안 게이트 (같은 2330건)

| 게이트 | 적중 | 비율 | 비고 |
|---|---:|---:|---|
| G0 `hp>75 && cr>5000` (현재) | **0** | 0.0% | 죽은 분기 |
| **G1 `cr>5000`** | **260** | **11.2%** | arc1 15 · arc2 8 · arc3 28 · **arc4 118 · arc5 91** |
| G2 `cr>3000` | 1306 | 56.1% | 너무 흔함 |
| G3 `cr>5000 && hp>50%` | **0** | 0.0% | HP를 50%로 풀어도 안 겹침 |
| G4 `cr>4000 && hp>40%` | 162 | 7.0% | |
| G5 `hp>75%` | 419 | 18.0% | **arc1 407** — 서사적으로 틀린 위치 |

G3 가 0 이라는 사실이 **임계값 문제가 아니라 상관 문제**임을 확정한다.
G5 는 결과를 arc1 에 몰아넣어 "지배"가 초반 엔딩이 된다.

## 사용자 결정 (Decision)

- [x] **G1 — 크레딧 단독.** 11.2% 의 엔딩, 그중 **80% 가 arc4/arc5**(지배가 서사적으로
  속한 곳). 밸런스 곡선 비용 **0** — 게이트는 전력이 아니라 **판정**이다.

## 결과 (Consequences)

- `ending_resolver.ts`: `if (ctx.credits > 5000)` — HP 조건 제거.
- **"돈이 의미 없다"에 소비처 없이 답한다.** 소비처 4개는 fitted 곡선에 자리가 없어
  기각됐다(ADR-0282/0284/0285/0286). **부를 엔딩 조건으로 쓰면 자리가 필요 없다** —
  주는 것이 아니라 읽는 것이기 때문이다.
- 크레딧이 드디어 **목적**을 갖는다: 많이 벌면 지배 엔딩에 닿는다.
- 테스트: `web/tests/adr0314-wealth-buys-control.test.ts` (3건) · `ending_resolver.test.ts`
  의 75% 경계 테스트를 새 규칙으로 갱신 · `ending_distribution.ts` 라벨 정정.
- 전체 **209 files / 4196 tests**.

## 열린 질문

- **(a) 임계값 5000.** G1 로 11.2% 다. 더 흔하게(3000 → 56%) 혹은 더 드물게 조절 가능.
  지금 값은 "최적 플레이의 후반 등급"에서 자연스럽게 도달하는 지점이다.
- **(b) 다른 엔딩 조건도 같은 병이 있는가.** `requiresFaction`(선언 0) · `requiresChoice`
  (선언 0) · `missionsCompleted>=3`(항상 1) 은 **도달 불가**로 문서화돼 있다(ADR-0270).
  control 이 그 목록에서 빠진 것은 이번이 처음이다. 나머지는 캠페인/선택 시스템이 필요하다.
- **(c) 경제의 나머지 절반.** 이 결정은 **수입**에 의미를 준다. **지출**은 여전히 비어 있다
  (intel ≈0, prep 스톡파일 share 0). 곡선에 자리가 없다는 결론은 유지된다.
