# ADR-0295: 흔적은 뺄 수 있다 — 몸으로 값을 낸다

**상태**: Accepted
**날짜**: 2026-11-08
**결정자**: 오너 ("b." — ADR-0294 (b))
**우선순위**: P2 (설계 · 선택지)
**관련**: [ADR-0294 — 처치는 흔적을 남긴다](./0294-every-kill-leaves-a-trace.md) · [ADR-0293 — 처치는 자기 몫을 낸다](./0293-a-kill-pays-its-bounty.md) · [ADR-0282 — 전리품은 지출](./0282-the-loot-stop-is-a-spend.md) · [ADR-0286 — 상점은 자리가 없다](./0286-the-shop-has-no-room.md)

> ADR-0294 는 **싸움의 비용**을 만들었지만 **빠져나갈 길**이 없었다. 비용에 답이 없으면 트레이드오프가
> 아니라 **함정**이다. 그래서 흔적을 뺄 수 있게 했는데 — **값을 크레딧으로 매긴 첫 설계는 측정으로
> 두 번 죽었다.** 남은 답은 **몸으로 내는 것**이다.

## 측정으로 죽은 설계 — 크레딧으로 빼기

`40cr/COST`(1회 400cr):
- g5 `48.8` vs 회피 `43.3` · g6 `19.4` vs `13.9` → **싸움이 +5.5pp 우세 = 트레이드오프 붕괴**.
- 이유: **돈이 용량을 찍어낸다.** 처치는 현상금(0293)을 주므로, 그 돈으로 흔적을 지우면 **순환이 닫힌다**.

가격을 올려 다시 쟀다:

| 가격 | g5 싸움/회피 | g6 싸움/회피 |
|---|---:|---:|
| 40cr | 48.1 / 43.3 | 20.8 / 13.3 |
| 100cr | 48.1 / 43.3 | 20.8 / 13.3 |
| 175cr | 45.0 / 43.3 | 20.8 / 13.3 |
| 190cr | 42.5 / 43.3 | 9.2 / 13.3 |

**어떤 가격도 두 등급을 동시에 균형에 두지 못한다** — 190cr 는 애초에 **살 수 없는 가격**이라
죽은 옵션이 된다. **크레딧 축은 답이 아니다.**

## 결정 (Decision)

**흔적은 HP 로 뺀다.** `VENT_COST = 10`, **`VENT_HP_PCT = 40`**(최대 HP 의 40%).

- 전리품 화면의 **6번 칸**: `6 VENT  120 HP — clear 10 COST → 45/100`
- **구매이지 전리품 선택이 아니다**: 화면을 닫지 않으므로 **카드를 포기하지 않는다**. 값은 HP 뿐이다.
- HP 가 값 이하면 거절(`Venting costs N HP — you have M.`).
- COST 는 0 에서 바닥(초과분 없음).

**왜 HP 인가**: 이것만이 **자원을 찍어내지 않는다**. 몸을 용량으로 **재배치**하는 것이고 총량은
그대로다. 그래서 ADR-0294 의 트레이드오프가 **구조적으로** 살아남는다.

## 측정 (Measurement)

`VENT_HP_PCT` 를 훑었다(48시드, `--cards best`, 싸움+vent vs 회피):

| vent 값 | g5 싸움/회피 | g6 싸움/회피 |
|---|---:|---:|
| 15% | 50.3 / 43.3 | **31.7** / 13.3 |
| 20% | 41.0 / 43.3 | 18.8 / 13.9 |
| 30% | 40.0 / 43.3 | 18.3 / 13.3 |
| **40%** | **40.0 / 43.3** | **14.6 / 13.9** |
| 없음(ADR-0294) | 40.0 / 43.3 | 14.6 / 13.9 |

**15% 는 싸움을 압승으로 만든다**(g6 +18.4pp) — 싼 밸브는 0294 를 되돌린다. **40% 는 ADR-0294 의
균형을 그대로 유지**한다.

전 등급 최종(48시드): g1 `100/100` · g2 `98.0/100` · g3 `85.6/89.2` · g4 `76.7/74.4` ·
g5 `40.0/43.3` · g6 `14.6/13.9` — **±3.6pp, 방향 불일정 = 거래 유지**.

### 정직한 한계 — 하네스에서는 거의 쓰이지 않는다

40% 는 비싸서, 이 봇은 48시드에서 **유효한 사용을 거의 하지 않는다**(수치가 없을 때와 동일).
그게 **의도된 결과**다: 싸게 만들면 트레이드오프가 무너지고, 비싸면 비상용 밸브가 된다.
옵션의 가치는 **"COST 가 바닥나 아무것도 못 쓰는 상태"를 플레이어가 탈출할 수 있다**는 데 있고,
그건 봇이 스스로 만들지 않는 상황이다.

## 결과 (Consequences)

- **비용에 답이 생겼다**: 막히면 몸을 팔아 숨통을 틔울 수 있다. 단 **이득이 아니라 재배치**다.
- **트레이드오프 보존**: 40% 는 ADR-0294 의 수치를 한 자리도 바꾸지 않는다.
- **전리품 화면이 6칸**: 카드 3 · 수리 · 정보 · vent. 다만 vent 는 **화면을 닫지 않는** 유일한 칸이다.
- **불변**: 교전당 곡선 · 저장 형식 · COST 상한.

## 열린 질문

- **(a) 세분화.** 지금은 10 COST 단위다. 5 COST / 20% 로 쪼개면 같은 비율로 **더 자주** 쓸 수 있다.
  균형은 같아야 하지만(비율 동일) 실제 사용 패턴은 다를 수 있다 — 측정 필요.
- **(b) HP 가 아니라 다른 것.** 예: **카드 한 장을 버리고** COST 를 되찾기. 값이 "성장"이면
  트레이드오프가 더 선명해진다.
- **(c) 화면이 예고할 것인가.** 지금은 흔적이 있을 때만 줄이 뜬다. 다음 교전의 **예상 흔적**을
  경로 카드에 보여주면(ADR-0294 (c)) vent 결정이 더 분명해진다.
