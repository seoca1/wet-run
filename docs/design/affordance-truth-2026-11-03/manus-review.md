## verdict (원문)

> 제안된 조치 A와 B는 UI 표시에 국한된 변경으로 밸런스 영향이 최소하이며 ADR 규약 위반 위험도 낮은 편이다.
> 다만 D(틱 아이스 이펙트 인덱스 수정)와 E(HUD 오버플로) 부분은 승률 및 어포던스 진실성에 직접적 영향을
> 줄 가능성이 커서 별도 검증이 필요하며, ADR-0251 규약의 준수 여부를 면밀히 점검해야 한다. C는 효과 라벨의
> 정직성 문제를 다루지만, 'effect 필드에 맞춘 라벨링' 이 현재 약속된 효과를 벗어나지 않도록 범위를 엄격히
> 제한해야 한다. 빠진 발견으로 HUD 문자열 길이와 로깅 메시지의 불일치를 추가로 확인해야 하며, 화면의 다른
> 어포던스 차이도 점검이 필요하다. 총괄적으로, **D를 독립 검증 묶음으로 분리하고 E를 즉시 해결하는 것이
> ADR-규약 준수와 어포던스 진실성 보장을 위해 바람직하며**, A-B-C의 표시 수정은 동일 릴리스에서 합리적이며
> 위험이 낮다. F는 ADR-0243의 변경을 피하기 위해 유지하는 것이 좋다.

## risks (원문)

- D: 전투 결과에 직접 영향 가능성으로 인한 승률 변화 위험(바이트 식별성 유지 목표와 충돌 가능성)
- E: HUD 어포던스 위반 가능성으로 즉시 수정 필요성이 강함(ADR-0251 위반 가능성)
- C: 라벨 정직화가 현재 세션의 실제 효과와 불일치 가능성 지속
- B: COST +N 표기가 실제 비용과 상충할 가능성 존재(표기 제거가 적절하나 남아있을 수 있음)
- A: UI 표시 수정은 안전하나, 종결 여부 분기에 따른 실제 상태 차이를 꼼꼼히 테스트해야 함

## missed_findings (원문)

1. HUD 40x60 레이아웃에서 우측 HUD 폭은 10열인데 27자 문자열(예: 'Choice: arc4_liberation_front')을
   그대로 넣는 것은 가독성과 어포던스에 심각한 위험이 있음. ADR-0251의 어포던스 진실성 원칙에 의문이 생김.
2. 손패 카드 5종의 effect 필드가 모두 'attack'인데 실제 부수효과가 카드 설명과 다르며, barrier/decoy 등으로의
   상태 토글이 발생하는 사례가 확인됨. 이 불일치가 UI 표시에만 국한된지, 전투 로직의 배선 변경 없이 충분히
   해결 가능한지 추가 근거 필요.
3. 결정적 테스트에서 마지막 ICE를 쓰는 카드의 COST 표기가 실제 비용과 다르게 보일 수 있어 킬 예측 표기
   자체의 신뢰도가 떨어짐. ADR-0251의 킬 예측 금지 규정과의 관계를 재확인 필요.
4. tickIceEffects에서 인덱스 결함으로 인해 앞 효과 만료 시 뒤 효과가 잘못 갱신되거나 복제되는 문제의
   재현이 가능하므로, 이 버그 수정은 전투 결과에 직접적인 영향을 줄 수 있음. 회귀 테스트 및 승률 기준선의
   byte-identical 보장을 요구.
5. 향후 세션으로 미룬다는 제안은 ADR-0251 규칙 5(약속된 화면 동작의 진실성)과 어긋날 가능성이 있음.
   HUD 오버플로/레이아웃 이슈는 즉시 처리하는 것이 바람직하나, 실행 순서에 주의 필요.
6. 다양한 화면(loot, 프로그램 카드 설명, 로그, 라벨)의 약속과 실제 동작 간의 차이가 여전히 존재하며,
   화면이 약속한 정보와 실제 정보 사이의 불일치가 추가로 발견될 수 있음.

## recommended_order (원문)

0. 기준선 고정 및 ADR 보호 장치 확립: 결정적 테스트 결과와 byte-identical 승률 기준선 유지 여부를 확인
1. A: 종결 노드 Loot 화면의 렌더링을 실제 상태와 일치시키고 종결/비종결 분기에 대한 회귀 테스트 추가
2. E: HUD의 10열 제약 하에서의 선택지 가독성 개선을 **즉시 반영**
3. B: 손패 COST 예측 표기를 제거하고 카드당 COST +N 표기를 제거 혹은 조건부로만 유지(실제 비용 확인 시에만 유지 여부 결정)
4. C: 프로그램 카드 라벨을 실제 효과 필드에 맞추되 이번 세션에는 부수효과 배선을 변경하지 않고 설명문 조정 가능 여부를 추가 검토
5. D: tickIceEffects 인덱스 수정은 **별도 검증 묶음**으로 처리. 의도된 효과 만료 시나리오에 대한 단위/통합 테스트 및 승률 영향 분석 필요
6. F: select→confirm 모델 도입 여부는 유지하되, 표시의 진실성과 ADR 준수를 위한 보완 검토 계속
7. 이후: 필요 시 E/A/B/C의 묶음과 D의 변경 사항을 포함하는 단일 릴리스로 묶되, 승률 및 바운스 테스트의
   바이트 식별성(byte-identical) 여부 재확인
