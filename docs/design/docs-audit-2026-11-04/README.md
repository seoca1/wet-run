# 문서·구조 감사 (2026-11-04) — 처음 시도한 시각

> **이 감사의 각도**: 링크 개수 세기·오타 지적이 아니다. **"문서가 코드와 어긋난 채로 굳는 구조"** 를 본다.

1. **측정 먼저** (의견 배제): 경로 존재 여부 · 수치 vs 실측 · ADR 네임스페이스 · 문서 구조 · 도구 커버리지.

3. **Jev** 로 수정 우선순위 판정.
4. 측정 → 수정 → **자동 검사기**로 회귀 방지.
