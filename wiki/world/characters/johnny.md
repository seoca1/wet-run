# Johnny (Wet Run Character — Johnny Mnemonic protagonist)

> **Primary source**: `../../../../Fiction/wiki/characters/johnny.md`

Wet Run adaptation of the iconic Sprawl data courier protagonist.

## Overview

**Johnny** is the protagonist of *Johnny Mnemonic* (1981) — a Sprawl data courier who stores information in his brain's wetware. He appears as a **quest-giving NPC** in Wet Run, embodying the canonical early-cyberpunk figure of the body-as-data-infrastructure.

## Game Mechanics

- **Role**: Information broker / quest giver
- **Faction**: Independent courier (associates with [[yakuza]] data markets)
- **Spawn conditions**: Available from mid-game (after player unlocks [[chiba-city]] access)
- **Quest type**: Data courier contracts (steal / deliver / decrypt missions)

## Lore Adaptation

Johnny represents the canonical "data-in-body" archetype:
- **Mnemonic wetware**: Stores encrypted data in brain
- **Activation codes**: Held by debt-collector (canonical vulnerability)
- **Combat inexperience**: Not a fighter — must use stealth / allies

## Game Mechanics Detail

- **Hire cost**: 5,000-50,000 eddies depending on data value
- **Mission types**: Steal ICE-protected data, deliver to corp buyers, decrypt archives
- **Risk factors**: Yakuza pursuit (heat mechanic), data corruption (encryption checks), neural damage (cyberware limit)
