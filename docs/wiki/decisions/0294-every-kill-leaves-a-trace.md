# ADR-0294: 처치는 흔적을 남긴다 — 싸움에 비례하는 비용

**상태**: Accepted
**날짜**: 2026-11-08
**결정자**: 오너 ("응." — ADR-0293 (a))
**우선순위**: P1 (설계 · 트레이드오프)
**관련**: [ADR-0293 — 처치는 자기 몫을 낸다](./0293-a-kill-pays-its-bounty.md) · [ADR-0292 — 드롭은 그 ICE 의 값](./0292-a-drop-is-worth-its-ice.md) · [ADR-0290 — 곡선 재기준화 + gate](./0290-the-curve-moves-and-the-core-opens-after-a-path.md) · [ADR-0229 — 곡선 재기준화](./0229-grade-curve-rebaseline.md)

> ADR-0293 은 g6 에 **보상** 축을 줬고, 그 측정이 남은 문제의 **모양**을 드러냈다:
> 비용 없이 보상만 늘리면 **"다 싸운다"가 완료율과 크레딧 모두에서 앞선다**. 그건 선택이
> 아니라 정답이다. 이 ADR 은 **싸움 횟수에 비례하는 비용**을 넣어 그 정답을 **거래**로 바꾼다.

## 먼저 기각한 안 — 덱 품질 gate (오너가 승인했던 안)

"코어는 덱이 충분히 강해야 열린다"는 **트레이드오프를 만들 수 없다**: 약한 덱이 **아예 들어갈 수
없게** 되므로 대안이 **사라진다**(`blind` 0%). ADR-0289 에서 gate 단독이 g4 를 12.5% 로 부순 것과
같은 실수다. **gate 는 선택을 만들지 못하고 제거한다.** 그래서 구현하지 않았다.

## 결정 (Decision)

**처치는 `tier` 만큼의 COST 를 남긴다** (`TRACE_COST_PER_TIER = 1`).

- `resolveVictory` 에서 `player.alarm = min(COST_LIMIT, alarm + Σ tier)`.
- 메시지: `… +1250 credits (bounty 200) · trace +5`.
- **COST 는 이미 이 게임의 시계**다: 프로그램이 소비하고, **리필되지 않으며**, 100 이면 아무것도
  못 쓴다. 즉 새 자원을 만들지 않고 **기존 자원에 뜻을 붙였다.**
- 상한은 `COST_LIMIT` 로 클램프 — 처치가 예산을 **소진**시킬 수는 있어도 **넘치게** 만들 수는 없다.

**왜 강도(strength)를 올리는 대신 이 축인가**: ADR-0293 에서 g6 교전 HP 상한을 110/125 로 올려
봤지만 **격차가 벌어졌다**(long 20.8 vs blind 9.2 / 4.2). 교전이 강해지면 **장비 없이 코어로 가는
쪽**이 먼저 무너지기 때문이다. 강도는 **싸움의 질**에 비례하고, COST 는 **싸움의 횟수**에 비례한다.
후자라야 두 전략이 만난다.

## 측정 (Measurement)

48시드, `--cards best`, 등급별 **싸움 대 회피**:

| 등급 | 모두 싸운다 | 최소 경로 | 차이 |
|---|---:|---:|---:|
| g1 | 100.0 | 100.0 | 0.0 |
| g2 | 98.0 | 100.0 | −2.0 |
| g3 | 85.6 | 89.2 | −3.6 |
| g4 | 76.7 | 74.4 | **+2.3** |
| g5 | 40.0 | 43.3 | **−3.3** |
| g6 | 14.6 | 13.9 | **+0.7** |

**모든 등급에서 ±3.6pp 이내이고, 방향도 일정하지 않다**(g4·g6 은 싸움이, g2·g3·g5 는 회피가 근소
우세). 즉 **정답이 아니라 거래**다. 대조: 흔적 비용이 없던 ADR-0293 상태에서는 g5 +6.3 · g6 +6.3
으로 **한 방향**이었고, ADR-0288 에서는 **+47.2pp** 로 회피가 압승이었다.

곡선은 단조 유지: `100 / 98.0 / 85.6 / 76.7 / 40.0 / 14.6`(싸움 기준).

`npm run balance`(교전당)는 **무영향** — 흔적은 교전 **후**에 붙는다.

## 결과 (Consequences)

- **처음으로 "얼마나 싸울까"가 진짜 결정**이 됐다. 보상은 카드(0292)·현상금(0293), 비용은 HP와
  **흔적(COST)**. 어느 쪽도 지배하지 않는다.
- **크레딧과 COST 가 한 몸이 됐다**: 강한 ICE 는 돈을 많이 주고 **예산을 많이 먹는다** — "벌었지만
  이제 값을 못 낸다"는 긴장이 생겼다.
- **불변**: 교전당 곡선 · 저장 형식 · 엔딩 구조. COST 상한(100)도 그대로.

## 열린 질문

- **(a) 흔적의 세기.** `tier × 1` 은 48시드에서 균형점이었다. `× 2` 는 g6 를 **회피 우세**로
  뒤집고(12.5 vs 13.5) g5 를 25.7 로 부순다 — 즉 **너무 세다**. 지금 값은 측정된 균형점이다.
- **(b) 회복 수단.** 흔적은 리필되지 않으므로 후반에 "값을 못 내는" 상태가 온다. 그게 의도지만,
  **크레딧으로 COST 를 사는** 길을 열면 ADR-0293 (c) 의 "런 안 크레딧 용도"가 닫힌다 — 전력을 사는
  것이므로 ADR-0286 교훈을 다시 통과해야 한다.
- **(c) 화면.** 지금은 승리 문구와 `COST n/100` 뿐이다. 경로 카드에 **예상 흔적**(`trace +12`)을
  보여주면 선택이 더 분명해진다 — ADR-0287 의 intel 과 겹치는 지점.
