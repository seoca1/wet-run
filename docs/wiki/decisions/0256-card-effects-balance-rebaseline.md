# ADR-0256: 카드 효과 밸런스 재기준선

**상태**: Accepted
**날짜**: 2026-11-03
**결정자**: 오너 승인 (2026-11-02 "추천대로 해줘" — 카드 실제 효과 배선을 포함)
**우선순위**: P1 (The Flatline — 밸런스 기준선, The Build — 검증 가능성)
**관련**: [ADR-0255 — 카드가 이름대로 동작한다](./0255-card-effects-are-real.md) · [ADR-0229 — grade curve 재기준선](./0229-grade-curve-rebaseline.md) · [ADR-0239 — VFX RNG 결합 해소](./0239-vfx-spawn-rng-decoupling.md) · [ADR-0224 — encounter band 커버리지 확대](./0224-encounter-band-coverage.md) · [ADR-0225 — encounter band 재캘리브레이션](./0225-encounter-band-recalibration.md)

> **이 ADR은 ADR-0255가 만든 밸런스 이동을 명시 수용한다.** ADR-0229 §3 의 규칙("오너가 밸런스 ADR로
> 명시 수용하지 않는 한 opening/PPL 출력은 byte-identical이어야 한다")에 따른 재기준선이다.
> ADR-0239 의 결정과 밸런스 의미는 건드리지 않는다.

## 컨텍스트 (Context)

ADR-0255가 손패 5장에 실제 효과를 배선했다. 카드의 효과가 생기면 곡선이 움직인다 —
이 게임에서 사망이 주된 위협이라 **살아남는 효과 하나하나가 승률을 크게 올린다**(피해 ↑ → 당하는
타격 수 ↓ → 생존 ↑). 그래서 곡선 이동은 효과를 "구성"한 숫자가 아니라 **연쇄**로 결정된다.

ADR-0229 는 ±3pp 창을 세웠다. ADR-0224·0225·0227 의 기능 변경도 ±3pp 를 넘어 ±10pp 수준
이동한 뒤 재기준선 ADR 로 받아들였다. 이번도 같은 성격이다.

### 측정 — 어떤 효과가 얼마나 움직였나

오프닝 곡선(고정 손패)에서 **효과 하나씩을 끄고** 재측정했다.

| 구성 | g1 | g2 | g3 | g4 | g5 | g6 |
|---|---|---|---|---|---|---|
| 효과 없음 (기준선) | 100.0 | 88.3 | 70.5 | 39.5 | 36.2 | 0.0 |
| 전부 켜짐 (최종) | 100.0 | 100.0 | 97.5 | 53.4 | 44.1 | 0.3 |
| shield 만 끔 | 100.0 | 100.0 | 99.6 | 61.5 | 45.0 | 3.0 |
| evade 만 끔 | 100.0 | 100.0 | 99.6 | 60.5 | 44.7 | 1.7 |
| empower 만 끔 | 100.0 | 100.0 | 99.6 | 66.0 | 44.4 | 2.0 |
| pierce 만 끔 | 100.0 | 100.0 | 99.6 | 65.7 | 44.4 | 0.7 |
| decoy 만 끔 | 100.0 | 100.0 | 98.5 | 55.0 | 43.8 | 1.0 |

읽히는 것:
- **decoy** 가 가장 큰 단일 기여자(g4 +14.7pp) — 1턴 완전 흡수가 한 턴 전체 HP를 건드린다.
  그래서 **50% 흡수**로 낮췄다.
- 나머지 네 효과는 각 +3.7 ~ +9.2pp.

**효과를 전부 끈 대조군이 기준선과 정확히 일치**한다(100.0/88.3/70.5/39.5/36.2/0.0) — 그러므로
곡선 이동은 오직 카드 효과에서 왔고, ADR-0255 의 부수 변경(치유 훅·PPL 덱 모델·설명문 파생)은
**밸런스 중립**이다.

## 고려한 옵션

### Option 1 — 이동이 없어야 하므로 효과를 되돌린다 (ADR-0254 상태로)
카드는 다시 전부 같은 일을 한다. 게임의 핵심 약속이 비어 있는 상태로 남는다. **거부.**

### Option 2 — 효과를 최소로 만들어 곡선을 ±3pp 안에 넣는다
실측: 어떤 개별 효과도 g4 를 +3.7pp 이상 움직인다. 5개를 모두 최소로 만들어도 합은
±3pp 를 넘는다. **이 게임의 밸런스에서는 어떤 생존 효과도 ±3pp 안에 들어오지 못한다.**
(측정 근거: 각 효과 단독 기여 표.)

### Option 3 — 한 번 재기준선한다 (선택)
ADR-0229 Option 1("현 달성 곡선을 새 기준선으로 삼는다")과 동일. 기능 변경이 의도된 것이므로
드리프트를 재기준선으로 기록한다.

## 사용자 결정 (Decision)

### 새 기준선

| 곡선 | 이전 (ADR-0239) | **새 기준선** |
|---|---|---|
| opening | 100.0 / 88.3 / 70.5 / 39.5 / 36.2 / 0.0 | **100.0 / 100.0 / 97.5 / 53.4 / 44.1 / 0.3** |
| PPL | 100.0 / 79.1 / 98.9 / 83.0 / 44.4 / 24.7 | **100.0 / 100.0 / 99.3 / 84.1 / 44.4 / 27.3** |

### 수용 근거

1. **곡선 형태가 유지된다** — 단조 감소, g6 은 여전히 치명적(0.3% / 27.3%).
2. **PPL 곡선은 ±3pp 창 안** — g3 +0.4pp, g4 +1.1pp, g5 ±0.0pp, g6 +2.6pp. 개발된 덱의 난이도
   감각은 거의 그대로다.
3. **opening 의 g2·g3 이동은 손패 구성에서 증폭된 것**이다 — 오프닝 손패 5장 중 4장이 효과
   카드다. 곡선 이동의 원인은 효과의 크기가 아니라 **손패 밀도**다. (아래 "남은 항목" (a).)
4. **ADR-0255 는 카드가 실제로 다른 일을 하도록** 만드는 것이 목적이었다. 여기서 효과를 다시
   되돌리면 그 목적이 사라진다.

### drift policy (ADR-0229 §3 계승)

- 이후 밸런스 변경은 이 기준선을 기준으로 ±3pp 창을 따른다.
- window 를 벗어날 때마다 신규 ADR 로 사유를 남긴다(재기준선 churn 금지).

## 결과 (Consequences)

- `web/tests/balance_sim.test.ts` — 새 기준선을 고정한다(문구도 "reproduces the ADR-0256 baseline").
- ADR-0239 의 결정·의미는 그대로다. **기준선 숫자만** 이 ADR 이 대체한다.
- 오너가 효과 수치를 다시 조정하려면 `PROGRAM_EFFECTS` 표 하나만 고치면 되고, 그때 새 ADR 이 필요하다.

## 열린 질문

- **(a) 오프닝 손패 구성.** 5장 중 4장이 지원 카드다. 공격 3 + 지원 2 로 큐레이션하면
  곡선 이동이 줄고 게임의 도입도 나아진다. 오너 결정.
- **(b) 효과 수치의 재조정 가능성.** `PROGRAM_EFFECTS` 한 표. 곡선이 다시 ±3pp 를 벗어나면
  이 ADR 을 갱신한다.
