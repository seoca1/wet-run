    Glossary - Sprawl 세계관 용어¶

    Primary source: ../../../../Fiction/wiki/works/ (Sprawl Trilogy)

    깊은 분석/원문 인용은 Fiction wiki 참조. 본 페이지는 게임용 요약.

    깁슨이 만든/사용한 용어들. 게임에서 일관되게 사용. 출처 표기 권장.

    기술¶

    용어 정의 원문
    Cyberspace / The Matrix 데이터의 의식적 환각, 데크로 접속하는 공간 Neuromancer 1
    The Matrix 위와 동의 Neuromancer
    Cyberdeck 사이버스페이스 접속용 컴퓨터 Neuromancer
    Console cowboy / Hacker / Jockey 데크 사용자 Neuromancer
    ICE Intrusion Countermeasures Electronics — 시스템 방어선 Neuromancer
    Black ICE 치명적 방어선 Neuromancer
    Program 데크에서 실행되는 공격/방어/유틸리티 소프트웨어 Neuromancer
    Construct ROM에 저장된 AI 인격 Neuromancer
    Wetware 생체 인터페이스, 신경접속 Neuromancer
    Biosoftware 생체-소프트웨어 하이브리드 Neuromancer
    Biochip 인체 내장형 칩 Neuromancer
    Biosoft 인체 내장 생체-소프트웨어 (Count Zero) Count Zero
    Simstim 시뮬레이트된 자극 — 감각 공유/녹화 Neuromancer / Mona Lisa Overdrive
    Cranial jack 두개골 잭, 사이버스페이스 접속 Neuromancer
    Microsofts 시야 필드 — microsoft (소형 화면) Neuromancer
    Trode 신경 전극 Neuromancer
    Meat 신체 — derogatory, "the body was meat" Neuromancer (Case)
    ROM Read-only memory, construct 저장 Neuromancer
    Memory 데이터 저장소 Neuromancer

    게임 내 사용 시 주의¶

    • 소설에서 사용된 정확한 철자 사용 (예: "Ono-Sendai" 한 단어)
    • 우리 게임에서도 동일하게 사용
    • 현대적 해석 / Cyberpunk 2077 / Shadowrun / D&D 등 다른 작품의 용어로 대체 금지
    • 새 용어를 만들 때는 깁슨 톤을 따를 것
    • 1-up / 2-up / 3-up 등 자키 등급은 우리 게임화 필요
