🌐 Wet Run — Browser MVP

Tier 1 MVP Experimental

A browser-native version of the Wet Run deck-building ICE-breaking core. Built per ADR-0199. Playable in your desktop browser — no install required.

▶ Play in Browser

What's included

  • 1 playable mission — first_jack (the canonical tutorial run)
  • ICE-breaking combat — real-time-with-pauses state machine ported from wet_run Python
  • ASCII Canvas2D renderer — Gibson neon palette on black
  • Save/load — localStorage JSON with schema versioning
  • Keyboard input — arrow keys + ENTER/SPACE/ESC/Q

What's NOT included (Tier 2+)

  • Full 209-mission campaign
  • Multiple bosses / ICE types
  • Multiple jockeys
  • Audio (Howler.js)
  • Mobile touch UI
  • Save migration from desktop wet_run
  • Multiplayer / cloud sync
  • Full i18n (English only)

System Requirements

Browser: Chrome / Firefox / Safari 17+ (desktop, 1280×800 or larger)
Input: Physical keyboard required (no touch in MVP)
Audio: None (silent MVP)
Network: Static files only (no backend, no account, no analytics)

Architecture

TypeScript + Canvas2D + Vite. Game data exported from wet_run/prototype/data/ via Python script → static JSON → TypeScript reads at runtime. Zero server-side logic.

Why MVP-first?

Counter-review (2026-08-25) rejected Pygbag-first as a "procrastination device" — migrating 48 files × 423 tcod call sites to pygame-ce would take 4-8 weeks and make ~50% of the 5811 existing Python tests obsolete. TypeScript + Canvas2D MVP is a single-step approach with a 4-week calendar budget and validates "Gibson tone" + UX before committing to full Tier 2 expansion.
