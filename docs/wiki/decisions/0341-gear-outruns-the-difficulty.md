# ADR-0341: 장비는 난이도를 넘어선다 — T6가 g5/g6를 95/99로 만든다

**상태**: Draft (오너 결정 대기)
**날짜**: 2026-11-19
**결정자**: 사용자
**우선순위**: P1 (장비 · 난이도)

## 컨텍스트 (Context)

전수 검증(2026-11-19)의 P4: 장비 착용 곡선(`npm run gear`)이 상단을 뒤집는다. ADR-0328 은 장비 9종을
"완만" 밴드로 재조정하며 목표를 *T6 g5/g6 ≈ 65/70* 로 적었지만, 측정은 그보다 훨씬 높다.

## 측정 (Measurement)

미션 완주율 (paired seeds, `npm run gear`):

| set | g1 | g2 | g3 | g4 | g5 | g6 |
|---|---|---|---|---|---|---|
| bare (기준선) | 100 | 100 | 83 | 83 | **26** | **42** |
| T1 | 100 | 100 | 85 | 85 | 28 | 49 |
| T2 | 100 | 100 | 98 | 97 | 40 | 64 |
| T4 | 100 | 100 | 100 | 100 | 60 | 77 |
| T6 | 100 | 100 | 100 | 100 | **95** | **99** |

- **T6 하나로 g5 26→95, g6 42→99.** 장비가 상단 난이도를 사실상 제거한다.
- ADR-0328 의 목표 밴드(T6 g5/g6 ≈ 65/70)보다 **+30 / +29pp** 높다.
- 크래프팅/드롭 경로(ADR-0329/0331)가 T6 를 **도달 가능**하게 만들면(현재는 경제상 어려움), 이 곡선이
  현실이 된다.

## 고려한 옵션

### Option A — 장비 파워를 더 낮춘다
- **설명**: ADR-0328 재조정을 한 번 더 아래로.
- **장점**: 상단을 되돌린다.
- **단점**: ADR-0328 이 이미 "저티어 아이템이 0이 되는 죽은 스탯"을 피하려 균일 스케일을 거부했다.
  더 낮추면 같은 함정으로 되돌아간다.

### Option B — ICE 난이도를 장비 기대치에 맞춰 올린다 (동시 설계)
- **설명**: g5/g6 의 ICE(HP/damage)를 "장비를 착용한 러너" 기준으로 상향. bare 곡선은 재기록.
- **장점**: 장비가 **보상**이자 **전제**가 된다(로그라이크의 정석). ADR-0328 의 "동시 설계" 요구와 일치.
- **단점**: bare 기준선(balance golden·survival target)을 **재기록**해야 한다(§ADR-0321 전례 — 시드 스트림·
  곡선 이동). P2(Option B, g4 난이도)와 **함께** 해야 상단/중단이 어긋나지 않는다.
- ⚠ **오너 튜닝 필요**.

### Option C — 수용 (장비 = 파워 판타지)
- **설명**: 장비의 목적은 "이겼다고 느끼게 하는 것"이니 95/99 를 의도로 본다.
- **장점**: 무료. 크래프팅 목표가 명확한 보상이 된다.
- **단점**: 후반 등급이 무의미해진다(모든 미션이 100%).

### Option D — 상한 (gear effect cap)
- **설명**: 장비 보너스 총합에 상한을 둬 상단을 보호.
- **장점**: bare 곡선을 안 건드린다.
- **단점**: 인위적. "더 좋은 장비"의 의미를 깎는다.

## 추천 (Recommendation)

**B(동시 설계)를 권장하되, P2 와 묶어 한 번에.** 장비를 보상으로 남기려면 난이도가 장비를 따라가야
한다 — 그게 ADR-0328 이 남긴 긴장의 정공법이다. 다만 bare 기준선 재기록이 따르므로 **오너 결정 +
측정 세션**이 필요하다. 당장 결정이 어렵면 **C(수용)** 로 두고 상단을 "장비 이후 콘텐츠"로 재정의하는
것도 일관된 선택이다.
